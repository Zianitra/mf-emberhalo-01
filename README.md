Emberhalo — an original browser arcade: guard a glowing lantern core, split drifting gloom wisps with a halo beam, chain combos, survive the surge. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts   # then open http://localhost:8080 in a desktop browser
```

## Play

- Move: mouse or WASD/arrows. Beam: hold left click or Space. Pause: P. Restart: R.
- Banish wisps before they touch the core; keep the combo alive; at combo x8+ the core surges.
